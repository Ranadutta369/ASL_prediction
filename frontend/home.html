Technology

Built With Modern AI Infrastructure

Three specialized neural networks working together to power recognition, sequence analysis, and gesture synthesis.

🧠 ASLClassifierV2
Deep MLP with skip connections for static letter recognition
⚡ Spatial-Temporal Transformer
Multi-head self-attention for dynamic sequence recognition
🎨 Sign Diffusion (DDPM)
Text-conditioned denoising diffusion for 3D gesture synthesis
🖐️ MediaPipe Hands
21-point 3D hand landmark tracking at 30+ FPS
🚀 ONNX Runtime
Cross-platform optimized model inference engine
⚙️ FastAPI
High-performance async REST API serving 3 model endpoints
